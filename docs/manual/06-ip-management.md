# 第 6 章 IP 管理

## 功能概述

IP 管理围绕「网段内的 IP 与 MAC 地址」展开四个子页：ARP 采集（登录网关设备采集整网段 IP-MAC 对照表）、网段管理（登记与统计 CIDR 网段）、异常检测（对比历史数据自动发现 IP/MAC 异动）、OUI 管理（MAC 前缀与厂商对照库）。进入 IP 管理后默认显示「ARP 采集」子页。

页面结构：顶部一行页签，从左到右为「ARP 采集 / 网段管理 / 异常检测 / OUI 管理」，每个子页内为各自的工具栏 + 统计卡 + 表格。

## 界面布局

四个子页共用「顶部页签 + 工具栏 + 统计卡区 + 数据表格」的纵向结构：

- ARP 采集：工具栏一行四按钮，下方统计卡、设备选择卡片（按需展开）、按设备折叠的结果面板。
- 网段管理：左右双表布局（左网段右明细）。
- 异常检测：统计五卡 + 内层「变更事件 / 排除 IP」页签。
- OUI 管理：统计三卡 + 工具行 + 表格。

## 逐元素详解

### ARP 采集子页

功能：从已配置 SSH 或 Telnet 通道的设备（通常是网关/核心交换机）上执行 ARP 表查询命令，把整网段的 IP-MAC 对照数据采集入库，作为网段统计与异常检测的数据源。

工具栏从左到右：

| 元素 | 触发条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- |
| 「全部采集」主按钮 | 点击 | 对全部可采集设备（有 SSH/Telnet 通道）逐台采集 | 采集中按钮转圈；完成提示「采集完成: N 台设备, M 条记录」；单台设备失败不影响其它设备（逐台独立入库），整批中断提示「操作失败（已成功写入的设备数据保留，失败设备已回滚）：…」 |
| 「采集选中 (N)」按钮 | 先勾选设备后点击 | 仅采集勾选的设备 | 未勾选时禁用；空选点不了；结果统计中「异常变更/弃用IP」显示为「-」（选中模式无聚合统计） |
| 「选择设备」/「收起设备列表」按钮 | 点击 | 展开/收起设备选择卡片 | 设备卡片内为设备表格（选择框/设备名称/IP/厂商/连接通道标签），右上角「全选 | 清空」快捷链接 |
| 「导出 ARP 表」按钮 | 有采集结果后可点 | 把当前 ARP 数据导出为 CSV 文件 | 无结果时禁用；成功提示「导出成功: {文件路径}」 |

采集过程中显示流动进度条。采集结果按设备折叠展示：每组标题「{设备名} ({设备IP})」+ 绿色标签「N 条」或红色「失败」标签；展开可见该设备的 ARP 明细表（列：IP 地址 / MAC 地址 / VLAN / 接口），失败的显示具体错误。

顶部统计卡（采集完成后显示）：「设备: N | ARP条目: M | 异常变更: X | 弃用IP: Y」。

**定时采集**：ARP 采集支持后台定时自动执行（默认约每 60 分钟一次，可配置），随应用启动自动开启；采集数据按保留策略自动清理（默认保留 90 天，到期自动删除最旧数据，每 IP 至少保留最新一条）。

**采集来源通道**：仅 SSH 与 Telnet 通道参与（Web/RDP 设备无法执行 ARP 查询命令）；多通道设备按默认通道优先 SSH/Telnet 的规则选择。

### 网段管理子页

功能：登记关注的网段（CIDR 形式），查看每网段的 IP 使用统计与明细。

页面为左右两表布局：左侧网段列表（约 4 成宽），右侧选中网段的统计与 IP 明细（约 6 成宽）。

工具栏从左到右：「添加网段」主按钮、「自动发现」（闪电图标）、「导出」（未选网段时禁用）。

**网段列表列**：名称 / 网段 / 掩码 / CIDR / 网关 / 来源（「自动发现」蓝色或「手动添加」）/ 操作（「查看」、编辑铅笔、删除垃圾桶带确认「确定删除此网段?」）。点击行任意位置即选中该网段（行高亮）并在右侧加载详情。

**右侧统计四卡**（选中网段后显示）：总IP / 已使用（绿色）/ 可用（蓝色）/ 使用率（%）。下方为 IP 明细工具行（「搜索 IP」输入框、「搜索 MAC」输入框、「搜索」按钮，支持回车触发），明细表列：IP 地址 / MAC 地址 / 厂商 / 状态（「已使用」绿色或「弃用」灰色）/ 接口 / 设备 / 最后发现，每页 20 条。

| 元素 | 触发条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- |
| 「添加网段」/「编辑网段」弹窗 | 工具栏或行编辑按钮 | 表单字段：名称（必填）、网络地址（必填，占位「如: 192.168.1.0」）、子网掩码（必填，占位「如: 255.255.255.0」）、网关（可选）、描述（可选多行） | 成功提示「创建成功」/「更新成功」 |
| 「自动发现」 | 点击 | 扫描已采集的 ARP 数据，归纳出尚未登记的网段并自动创建 | 有新网段提示「发现 N 个新网段」并刷新列表；无则提示「未发现新网段」；来源列标「自动发现」 |
| 「导出」 | 选中网段后点击 | 导出该网段使用情况为 CSV | 未选网段禁用；提示「导出成功: {路径}」 |
| 截断提示条 | 明细超出单次加载上限 | 表格上方黄色条「已显示前 N 条 / 共 M 条」 | 应对建议：点「导出」获取该网段完整 IP 清单 CSV |

### 异常检测子页

功能：每次 ARP 采集后与历史基线比对，自动记录三类异常事件，供人工确认/排除/导出。

顶部统计五卡：总事件 / 未确认（红色）/ MAC变化 / 新IP / IP重用。

**异常类型**：

| 类型 | 标签颜色 | 含义 |
| --- | --- | --- |
| 新IP（new_ip） | 蓝色 | 网段中首次出现的 IP 地址 |
| MAC变化（mac_changed） | 橙色 | 同一 IP 的 MAC 地址与历史记录不同（可能是换了网卡或存在 ARP 欺骗） |
| IP重用（ip_reused) | 紫色 | 原本弃用的 IP 重新出现 |

子页内两层页签：「变更事件」与「排除 IP」。

**变更事件页签**工具栏从左到右：

| 元素 | 行为 | 规则与限制 |
| --- | --- | --- |
| 「全部确认」 | 一键确认全部未确认事件，提示「已确认 N 条」 | 无未确认事件时禁用 |
| 「删除选中 (N)」红色按钮 | 删除勾选的事件（气泡确认「确定删除选中的事件?」） | 未勾选禁用；提示「已删除」 |
| 「排除选中 IP」 | 把勾选事件的 IP 加入排除规则（不再参与异常检测） | 未勾选禁用；提示「已排除 N 个 IP」 |
| 「导出全部」 | 导出全部变更事件 CSV | — |
| 「导出未确认」 | 仅导出未确认事件 CSV | — |

**变更事件表**列：IP / 类型（彩色标签）/ 原 MAC / 新 MAC / 检测时间 / 状态（「已确认」绿色或「未确认」红色）/ 操作（未确认行有「确认」链接；历史图标按钮打开「IP 绑定历史」弹窗）。每页 20 条，可勾选多行。

**「IP 绑定历史」弹窗**：显示该 IP 历史上绑定过的所有 MAC（列：MAC / 首次发现 / 最后发现 / 状态「活跃」或「非活跃」），用于人工研判 MAC 变化是否正常。

**排除 IP 页签**：工具行「添加排除规则」按钮 + 说明文字「支持 IP、CIDR(192.168.1.0/24)、通配符(192.168.1.*)」。表格列：IP/CIDR / 描述 / 操作（删除，带确认）。添加弹窗两输入框：「IP / CIDR / 通配符」与「描述(可选)」。

### OUI 管理子页

功能：维护 OUI（MAC 地址前 6 位十六进制与网卡厂商的对照表）。系统自带基础库，可自定义扩充；网段明细中的「厂商」列与设备 MAC 识别都依赖它。

顶部统计三卡：总条目 / 自定义 / 厂商数。

工具栏从左到右：

| 元素 | 行为 | 规则与限制 |
| --- | --- | --- |
| 搜索框「搜索 OUI 前缀或厂商名称」 | 输入约 0.3 秒后自动搜索 | 清空恢复全量列表 |
| 「添加」主按钮 | 弹「添加 OUI」表单：OUI 前缀（必填，占位「6位十六进制，如: 001122 或 00:11:22」）、厂商名称（必填） | 成功提示「添加成功」；列表中显示为「自定义」蓝色标签 |
| 「批量导入」 | 弹批量导入窗，多行文本每行「OUI前缀,厂商名称」（如 001122,Huawei） | 无有效行提示「无有效数据」；成功提示「成功导入 N 条」 |

表格列：OUI 前缀（显示为 xx:xx:xx 格式）/ 厂商名称 / 类型（「自定义」蓝标签或「系统」灰标签）/ 操作（编辑；仅自定义条目可删除，系统条目无删除按钮）。每页 20 条。

## 定时采集与数据保留

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 定时采集 | 开启，约每 60 分钟一次 | 随应用启动自动运行，无需人工触发；手动「全部采集/采集选中」随时可叠加 |
| 数据保留 | 90 天 | 超期数据自动清理；每个 IP 的最新一条记录永不删除，保证现状可查 |
| 采集通道 | SSH / Telnet | 按设备已配置通道执行；两类都有时按默认通道规则取命令行通道 |

## 异常研判指引

| 事件类型 | 常见原因 | 建议动作 |
| --- | --- | --- |
| 新IP | 新设备上线 / 临时接入 / 未登记私接设备 | 核对资产台账：登记了的点「确认」，明确合法；不明来源先排查 |
| MAC变化 | 更换网卡 / 虚拟机迁移 / ARP 欺骗攻击 | 点历史图标看绑定轨迹：单次变更且有人工变更记录则确认；MAC 反复跳变需按 ARP 欺骗排查 |
| IP重用 | DHCP 正常回收再分配 / 静态 IP 被新设备占用 | 核对新占用设备身份；确属正常则确认，反复异常则检查地址规划 |
| 噪声型 IP（打印机、访客 Wi-Fi 等） | 动态性强的地址天然频发事件 | 勾选后「排除选中 IP」加入排除规则 |

## 典型操作流程：从零建立 IP 监控

1. 在 [第 5 章](./05-devices.md) 添加网关设备（如「核心交换机-01」，192.0.2.1 为示例），配置 SSH 通道凭证。预期测试连接通过。
2. 切到 IP 管理 → ARP 采集子页，点「全部采集」。预期按钮转圈、出现流动进度条，完成后提示「采集完成: 1 台设备, N 条记录」，折叠面板出现该设备与绿色「N 条」标签。
3. 切到网段管理子页，点「自动发现」。预期提示「发现 M 个新网段」（ARP 数据中归纳出的地址段自动登记，来源列显示蓝色「自动发现」）。
4. 点击左侧某网段行。预期右侧出现统计四卡（总IP/已使用/可用/使用率）与 IP 明细表。
5. 等待下一次采集（或手动再采一次）后，切到异常检测子页。预期统计卡出现事件计数（首次采集只建基线，第二次起才产生异常）。
6. 逐条研判变更事件：正常的变更点「确认」；已知良性且不想再报的 IP 勾选后点「排除选中 IP」；拿不准的点历史图标看该 IP 的 MAC 绑定轨迹。

## 规则与限制

| 规则 | 说明 |
| --- | --- |
| 采集数据写入 | 单设备单事务：一台失败只回滚该设备，已成功设备的数据保留 |
| 首次基线 | 全新环境的第一次采集只建基线不报异常；从第二次采集起开始比对产生异常事件 |
| 排除规则生效 | 加入排除清单的 IP/CIDR 不再产生异常事件（已产生的不追溯删除） |
| 数据保留 | ARP 数据默认保留 90 天自动清理（每 IP 至少保留最新一条永不删） |
| 单次加载上限 | 网段 IP 明细默认上限 2000 条、OUI 默认 5000 条、异常事件默认 100 条，超出显示截断提示条并可用 CSV 导出获取全量 |
| 导出格式 | 全部导出为 CSV 文件，导出后提示保存路径 |
| OUI 删除保护 | 系统内置条目不可删除，仅自定义条目可删改 |
| IPv4 only | 网段与 IP 计算仅支持 IPv4 |

## 数据流转说明

四个子页共享同一份 ARP 采集数据，理解流转关系有助于定位问题：

```
ARP 采集（数据入口） ──► 网段管理（按 CIDR 归属统计 IP 使用）
        │
        └──► 异常检测（与历史基线比对产生变更事件）
                 │
                 └──► 排除 IP（人工屏蔽噪声）

OUI 管理（独立基础库）◄── 供网段明细「厂商」列识别
```

- 网段的「已使用」口径来自 ARP 数据，不是主动扫描：某 IP 只要在最近采集中出现即计入。
- 异常事件在每次采集入库时自动产生，无需手动触发检测。
- OUI 库更新（新增自定义条目）后，明细中的厂商列在下次加载时按新库识别。

## 网段明细字段说明

| 字段 | 含义 |
| --- | --- |
| IP 地址 | 网段内出现的 IPv4 地址 |
| MAC 地址 | 该 IP 当前绑定的 MAC（最近一次采集值） |
| 厂商 | 按 OUI 库识别的网卡厂商（识别不到为空） |
| 状态 | 已使用（近期采集出现过）/ 弃用（历史出现过、近期未再见） |
| 接口 | 采集设备上记录该表项的接口名 |
| 设备 | 若该 IP 对应已登记的设备则显示设备名 |
| 最后发现 | 最近一次采到该 IP 的时间 |

## 常见问题

**Q1：采集时部分设备显示红色「失败」标签？**
该设备登录失败（凭证错误/网络不通/超时），展开可见具体错误。到设备管理页修正该设备凭证后重新采集；失败不影响其它设备的数据。

**Q2：「异常变更」「弃用IP」显示「-」？**
「采集选中」模式只统计采集条目数，不计算与历史的比对汇总；用「全部采集」可获得完整统计。

**Q3：明明换了设备网卡，怎么不再报 MAC 变化？**
该 IP 可能已被加入排除规则——到「排除 IP」页签检查并删除对应规则即可恢复检测。

**Q4：网段统计的「已使用」是什么口径？**
以 ARP 采集数据为准：最近一次采集中出现过（且非弃用状态）的 IP 计为已使用。

**Q5：列表上方黄色「已显示前 N 条」提示影响我找目标数据？**
这是单次加载上限的保护。用搜索框（IP/MAC/厂商/OUI 关键词）缩小范围，或点「导出」拿全量 CSV 离线分析。

**Q6：想批量补充公司自有设备的厂商对照？**
用 OUI 管理的「批量导入」，每行「OUI前缀,厂商名称」粘贴多行一次导入。

**Q7：为什么第一次采集后异常检测里什么都没有？**
首次采集只建立基线（记录现状），从第二次采集起才会与基线比对产生「新IP / MAC变化 / IP重用」事件。

**Q8：导出的 CSV 文件在哪？**
导出成功提示中包含完整保存路径（默认下载目录）；CSV 可用 Excel/WPS 直接打开。

**Q9：多台设备都能采到同一网段的 ARP，会重复计数吗？**
按 IP 维度聚合入库，同一 IP 只有一条最新记录；采集来源设备不同不影响统计口径。

## 本章术语

| 术语 | 解释 |
| --- | --- |
| ARP 表 | 设备上 IP 与 MAC 地址的对照缓存表，是采集的数据源 |
| 网段 | CIDR 形式登记的地址范围（如 192.0.2.0/24），统计与检测的单位 |
| 基线 | 第一次采集建立的历史参照，之后采集与它比对产生异常 |
| 新IP | 网段中首次出现的 IP 地址（异常类型之一） |
| MAC 变化 | 同一 IP 关联的 MAC 改变（换网卡或 ARP 欺骗的信号） |
| IP 重用 | 已弃用的 IP 重新上线（异常类型之一） |
| 排除规则 | 按 IP / CIDR / 通配符排除的对象，不再参与异常检测 |
| OUI | MAC 地址前 6 位十六进制厂商编号段 |
| 通配符 | 形如 192.168.1.* 的范围表达，星号匹配任意值 |
| 弃用 IP | 历史出现过、近期采集中未再见的 IP |
| 保留策略 | 采集数据自动清理的期限规则（默认 90 天） |
| 截断信封 | 超出单次加载上限时返回 {rows,total,truncated} 的数据安全机制 |
