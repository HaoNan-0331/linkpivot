# 第 3 章 界面总览

本章带你认识登录后的主界面骨架与全软件通用的交互约定。之后各章不再重复这些内容。

## 三栏布局

登录成功后，整个窗口从左到右分为三栏：

| 栏 | 宽度 | 内容 |
| --- | --- | --- |
| 侧边栏 | 固定 200 像素 | 顶部品牌位 + 七模块导航菜单；在拓扑管理页时下方追加拓扑工具栏 |
| 内容区 | 弹性占满剩余空间 | 当前模块的页面 |
| 详情栏 | 默认折叠；展开后 240 像素～窗口宽度 40% 之间可调 | 预留的设备详情面板位（当前为占位说明） |

**第 1 步：看侧边栏。**
侧边栏顶部是一个 48 像素高的品牌位，显示加粗的「拓扑管理」字样；其下是七个导航菜单项，从上到下依次为：拓扑管理、设备管理、IP 管理、AI 助手、知识库、日志审计、系统设置。每项左侧带图标，当前所在页面对应的菜单项高亮显示。

预期看到：登录后「拓扑管理」处于选中高亮态，内容区显示拓扑画布。

**第 2 步：切换页面。**
点击任意菜单项，内容区整体切换为对应模块页面。注意两点：

- 页面切换即卸载重建——离开拓扑页再回来，画布视图状态（缩放/平移）不保留（拓扑数据本身不丢失）。
- 在拓扑管理页时，侧边栏菜单下方会多出一段拓扑工具栏（画布操作按钮的另一个入口，功能与画布内工具栏一致，见 [第 4 章](./04-topology.md)）。

**第 3 步：认识右侧详情栏。**
内容区右缘有一条竖直的窄把手（宽 8 像素的命中区，视觉上是中间一个 12×32 像素的圆角小竖条）。它有两种手势：

- **单击**（按压期间基本没移动）：展开或收起详情栏，一次到位。
- **按住左右拖动**：连续调整详情栏宽度；从折叠状态直接拖开也有效。

展开后，详情栏显示的是占位说明内容（「详情栏（预留）」标题、说明文字与一个挂载时刻时间戳）。这是为后续版本的设备详情面板预留的位置——在拓扑中点选设备后右侧常驻展示设备详情的能力尚在开发中，当前版本按代码实态即为预留占位。占位内容里的「挂载时刻」时间戳有个用途：折叠再展开，时间戳不变，说明折叠只是把栏藏起来、里面的状态没有丢。

详情栏的宽度规则：

| 规则 | 值 |
| --- | --- |
| 最小宽度 | 240 像素 |
| 默认展开宽度 | 320 像素 |
| 最大宽度 | 窗口宽度的 40%（窗口很窄时保底 240 像素） |
| 默认状态 | 折叠 |
| 记忆 | 宽度与折叠状态写入本地存储，重启后保持 |
| 拖拽中 | 拖动把手时内容不闪烁、画布不重排；窗口尺寸变化时已展开宽度自动重新收敛到上限内 |

## 启动到主界面的完整流程

整个应用启动后的界面流转：

1. **加载页**：居中大转圈。
2. **初始化管理员**（仅全新安装）：见 [第 2 章](./02-install-login.md)。
3. **登录页**：见 [第 2 章](./02-install-login.md)。
4. **主界面**：三栏布局，默认落在拓扑管理页；若启动检测到新版本且未被压制，会自动弹出升级提示弹窗（见 [第 12 章 自动更新](./12-update.md)）。

## 通用交互约定

以下是贯穿所有页面的交互风格，认识一次即可：

### 胶囊按钮

主要按钮为胶囊形态（圆角明显的圆头按钮），蓝色主按钮表示当前推荐动作；次要动作为描边或纯文字按钮。危险操作（如删除）的按钮平时不带红色，鼠标悬停时才变红，避免误触也避免视觉噪音。

### 悬停显形的细滚动条

所有滚动区域使用 8 像素宽的细滚动条，平时隐藏或弱化显示，鼠标悬停到滚动区域时滚动条变清晰。列表、对话区、弹窗内滚动区均遵循此约定。

### 分页与截断提示条

大数据列表（IP 明细、OUI、异常记录、经验列表等）采用分页表格，右下角分页器显示「第 X-Y 条 / 共 Z 条」的范围式统计。当单次查询结果超出安全上限被截断时，列表上方出现黄色提示条：「已显示前 N 条 / 共 M 条」，并附带应对建议（如收紧筛选条件）。这是数据安全上限机制，不是 bug。

### 弹窗与提示

- 操作反馈（成功/失败）以右上角或顶部居中的轻提示（Toast，几秒后自动消失的黑底白字条）出现。
- 二次确认、表单编辑等使用居中模态弹窗（遮罩背景、点击遮罩或按 ESC 通常可关闭；下载进行中等不可中断场景会禁用这三者，见第 12 章）。

### 错误边界

任何页面渲染发生异常时，不会整应用白屏，而是显示降级页面：标题「程序出现异常」、具体错误信息，以及两个按钮——「重载应用」（主按钮，刷新整个应用）与「尝试恢复」——错误被隔离在局部区域，其他功能区不受影响。

### 表格通用行为

列表页的表格列头可点击排序的会显示排序箭头；列宽不足时内容以省略号截断，悬停可见完整内容的提示气泡；长文本字段（备注、路径等）普遍如此处理。

## 页面路由与书签

灵枢使用哈希路由（地址形如 `#/topology`、`#/devices`……）。八个路由：

| 路径 | 页面 |
| --- | --- |
| `/topology` | 拓扑管理（默认页，登录后首先进入） |
| `/devices` | 设备管理 |
| `/ip-management` | IP 管理 |
| `/ai` | AI 助手 |
| `/knowledge-base` | 知识库 |
| `/logs` | 日志审计 |
| `/settings` | 系统设置 |

## 常见问题

**Q1：右侧那条竖把手是干什么的？**
详情栏的折叠/调宽把手。单击展开或收起，拖动调宽度。当前版本详情栏内是预留占位说明。

**Q2：我在拓扑页摆好的画布，切到设备管理再回来变了？**
页面切换会重建画布组件，视图状态（缩放/平移位置）不保留；但节点位置、连线等拓扑数据已实时保存，回来时数据还在，只是视图复位。

**Q3：列表上方出现黄色「已显示前 N 条」提示是什么意思？**
单次查询结果超过了安全上限，只展示了前 N 条。按提示收紧筛选（如选择网段、时间范围）即可看到目标数据。

**Q4：按钮为什么悬停才变红？**
危险按钮的防误触设计：平时中性色，确认要点时（悬停）才呈现红色，减少误点删除类操作的概率。

**Q5：界面显示「程序出现异常」怎么办？**
先点「尝试恢复」重试局部渲染；无效则点「重载应用」。这是错误隔离机制的降级页面，说明刚才的操作触发了渲染异常，重载后一般可继续使用；若稳定复现，记下 subTitle 中的错误信息反馈给维护者。

## 本章术语

| 术语 | 解释 |
| --- | --- |
| 三栏布局 | 侧边栏（200px 固定）+ 内容区（弹性）+ 详情栏（可拖可折叠）的主界面结构 |
| 把手 | 拖拽调整详情栏宽度的窄条控件，单击可展开/收起 |
| 哈希路由 | 地址中 # 号后的路径段，用于区分当前页面 |
| Toast | 操作后几秒自动消失的轻量提示条 |
| 模态弹窗 | 带遮罩、需要先处理完才能回到页面的居中窗口 |
| 错误边界 | 捕获页面渲染异常并显示降级页面、避免整应用白屏的机制 |
| 截断提示条 | 查询结果超出上限被截断时列表顶部的黄色提示 |
| 省略号截断 | 列宽不足时文本以 … 截断、悬停看全文的展示方式 |
