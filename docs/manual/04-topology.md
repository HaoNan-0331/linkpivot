# 第 4 章 拓扑管理

## 功能概述

拓扑管理是灵枢的核心页面（登录后默认进入）：以交互画布呈现网络设备（节点）与连接关系（连线），支持手动搭建、自动发现、自动布局、批量整理、导入导出。画布基于 React Flow（一个支持缩放、拖拽、框选的流程图渲染库）实现。

## 界面布局

拓扑页整体分三处：

1. **画布**：占据内容区全部空间。浅色点阵网格背景；左下角是缩放控制条（放大/缩小/适配视图按钮）；右上角是小地图（MiniMap，全图缩略导航图，显示节点分布与当前视野框，点击可跳转）。
2. **画布右下角两个悬浮圆形按钮**：从右往左分别是「+」（添加设备到拓扑，主色大圆钮）和「放大镜」（拓扑自动发现，普通大圆钮）。悬停可见提示文字「拓扑发现」等。
3. **侧边栏下方拓扑工具栏**（仅在拓扑页显示）：位于七模块菜单下方，「拓扑操作」小标题下从上到下依次为：拓扑选择下拉框、新建、保存、删除、导入、整理布局、导出七个控件。

## 逐元素详解

### 侧边栏拓扑工具栏

| 元素 | 位置 | 触发条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- | --- |
| 拓扑选择下拉框 | 工具栏顶部 | 点击展开 | 列出全部拓扑（按最近更新在前），选择后加载对应拓扑到画布；可清空 | 布局预览未保存时切换会弹确认框（见下） |
| 「新建」按钮 | 下拉框下方 | 点击 | 弹出「新建拓扑」小窗，输入名称创建空拓扑 | 名称留空点创建提示「请输入拓扑名称」；成功提示「创建成功」 |
| 「保存」按钮 | 新建下方 | 点击 | 立即保存当前画布到数据库 | 未选拓扑时禁用；成功提示「保存成功」；预览态下点保存等价于「保存布局」（见布局预览） |
| 「删除」按钮 | 保存下方 | 点击 | 弹气泡确认「确定删除此拓扑？」，确认后删除当前拓扑 | 未选拓扑时禁用；红色危险按钮；删除失败提示「操作失败，数据已回滚无变化：…」（删除是事务操作，失败即整体回滚） |
| 「导入」按钮 | 删除下方 | 点击 | 打开文件选择器（仅接受 .json 文件），读入后校验 | 非法 JSON 提示「无效的JSON文件」；成功提示「导入成功」并自动切到导入的拓扑 |
| 「整理布局」按钮 | 导入下方 | 点击 | 对画布执行自动布局，进入布局预览态 | 未选拓扑时禁用；按钮悬停提示按选中状态动态变化（见「整理布局」小节） |
| 「导出」按钮 | 最下方 | 点击 | 将当前拓扑导出为 JSON 文件下载（文件名为拓扑名.json） | 未选拓扑时禁用；成功提示「导出成功」 |
| 「布局预览尚未保存」确认框 | 弹窗 | 预览态下切换拓扑时弹出 | 「放弃修改」（红色，确认切换并丢弃预览）或「继续编辑」（留在原拓扑） | 防止误离开丢失未保存的布局调整 |

### 画布节点

节点是从设备抽象出的图形块，居中显示设备类型图标（路由器/交换机/防火墙/服务器/通用设备五种图标），图标上方显示设备名称（加粗），下方显示 IP 地址（小字）。选中节点时图标外出现蓝色描边与浅色底。节点四边各有连接锚点（上/下/左/右各一对小圆点：蓝色为入端、绿色为出端）。

| 操作 | 触发条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- |
| 拖动节点 | 按住节点移动 | 节点跟鼠标移动，松手落位 | 拖动中显示对齐参考线（见下）；与其它节点重叠时松手会把被压节点平滑弹开到最近空位（被拖节点位置不变） |
| 单击节点 | 点击节点 | 选中（出现选中态边框），画布中出现选区工具条 | — |
| 框选 | 在空白处按住拖出虚线框 | 框内节点与连线全部选中 | 配合选区工具条做批量操作 |
| 双击节点 | 快速双击 | **连接设备**，按通道配置走三分支（见下表） | 连接动作详见 [第 11 章 远程终端](./11-remote-terminal.md) |
| 编辑属性 | 选中单个节点后点选区工具条「编辑属性」 | 弹出「编辑节点属性」窗 | 见下节 |

**双击连接三分支**（按设备当前已配置的通道数自动判定）：

| 分支 | 判定条件 | 行为 |
| --- | --- | --- |
| 零通道 | 设备未配置任何登录通道 | 弹出「编辑设备」表单，顶部黄色提示「该设备尚未配置登录通道：补配任一通道的凭证并保存后，即可双击连接」，并自动定位到最可能要配的通道页签（按设备原连接方式推断，无则 SSH 页签） |
| 单通道 | 恰好配置了一类通道 | 不弹选择框，直接用该通道连接 |
| 多通道 | 配置了两类及以上 | 弹出「连接 {设备名}」选择框：每行一个通道（标签 + 登录描述如 `user@192.0.2.1:22` 或 Web URL），命中的行尾显示「上次使用」徽标；预选规则 = 上次使用 > 默认通道 > 固定顺序（SSH/Telnet/Web/RDP）首个；点「连 接」确认并记住本次选择（记忆按设备保存，下次双击预选它），点「取 消」放弃 |

双击连接失败时按通道提示归因：「SSH 连接失败」「Telnet 连接失败」「Web 界面 连接失败」「RDP 远程桌面 连接失败」（无法归因时提示「连接失败」）。

### 选区工具条

选中节点或连线后，浮动出现在选区中心上方（自动跟随拖动），内含操作按钮，从左到右：

| 元素 | 显示条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- |
| 「编辑属性」按钮 | 选中了节点 | 打开节点属性编辑窗 | 仅单个节点时有意义（多选时编辑的是选中集第一个） |
| 左对齐 / 右对齐 / 顶部对齐 / 底部对齐 | 选中 ≥2 个节点 | 将选中节点沿对应方向排齐 | 悬停有中文提示 |
| 水平均分 / 垂直均分 | 选中 ≥3 个节点可用 | 在水平/垂直方向上等间距分布 | 不足 3 个时按钮禁用，悬停提示「需要至少 3 个节点」 |
| 「删除」按钮 | 有任何选中 | 删除选中的节点与连线（含选中节点关联的连线） | 红色危险按钮，即时生效（无确认框），随自动保存落库 |

### 节点属性编辑窗（「编辑节点属性」）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 设备名称 | 是 | 留空提示「请输入设备名称」 |
| IP 地址 | 是 | 留空提示「请输入 IP 地址」 |
| 设备类型 | 是 | 下拉五选一：路由器/交换机/防火墙/服务器/通用设备 |
| 厂商 | 否 | 占位提示「华为、Cisco、H3C...」 |
| 型号 | 否 | 占位提示「S5735-L48T4X」 |

此编辑是设备台账的单一写路径：保存时同步更新设备表并级联刷新所有拓扑中的对应节点显示（设备管理页与拓扑页数据永远一致）。改名冲突（与其他设备重名）会提示「保存失败：…」且不改动画布。厂商/型号清空即真实清空（空串有效）。

### 连线

从节点边缘锚点按住拖到另一节点锚点松开即可创建连线，随后弹出「连接接口配置」窗：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 源接口（{源设备名}） | 是 | 占位提示「例: GigabitEthernet0/0/1」，留空提示「请输入源接口名称」 |
| 目标接口（{目标设备名}） | 是 | 同上 |

确认后连线生成，线中点显示接口标签（格式「源接口 — 目标接口」）。连线自动选择两端最近的锚点方位走直线，拖动节点时连线与标签实时跟随。单击选中连线后可用选区工具条删除。接口名称可留作后续补充（标签只在有值时显示）。

### 对齐参考线与防重叠

- **参考线吸附**：拖动节点时，当节点与其它节点的边缘/中心/中线接近对齐（阈值约 6 画布像素）时，节点自动吸附对齐并显示一条贯穿两者的参考线，松手落位。
- **防重叠弹开**：松手时若落点压住其它节点，被压节点自动弹开到最近空位（150 毫秒平滑滑动），拖动的节点位置保持不动；多台被压时连锁让位（有界深度）。
- 节点默认尺寸 80×60 像素；自动布局节点间距约 260 像素。

### 整理布局（自动布局）

点击侧边栏工具栏「整理布局」按钮，按当前选中状态执行三种模式（自研星型分层放射算法，无第三方布局库）：

| 选中状态 | 模式 | 行为 | 按钮悬停提示 |
| --- | --- | --- | --- |
| 未选中 | 全图星型分层 | 剔除「叶子」设备（只连一条线的末端设备）后，选连接度最高的设备定在中心，其余按连接层级一圈圈向外放射排列 | 「未选中：按连接层级星型排列全图」 |
| 选中 1 台 | 定根全图 | 以该设备为中心，全图按层级放射排列 | 「已选 1 台：以该设备为中心排列全图」 |
| 选中多台 | 仅整理选中集 | 只重排选中的设备，其余不动 | 「已选多台：仅整理选中设备」 |

**布局预览态**：执行整理后不立即保存，画布顶部居中出现白色横幅：「已生成布局预览，可直接拖拽微调」+「保存布局」（主按钮）+「撤销布局」。预览期间：

- 可以继续拖拽节点微调，微调结果与布局结果在点「保存布局」时一并落库（成功提示「布局已保存」）；
- 「撤销布局」一键恢复布局前的全部位置（提示「已撤销，恢复布局前位置」，不弹确认）；
- 自动保存挂起（预览期间的改动不会偷偷落库）；此时切换拓扑会弹「布局预览尚未保存」确认框防误离开；
- 整理失败（如空画布、异常）提示「布局整理失败，画布未改动」，画布保持原样。

### 自动保存

拓扑的节点位置、连线等改动在停止操作约 1 秒后自动保存到数据库（无需手动点保存）；侧边栏「保存」按钮用于立即保存并得到「保存成功」提示。两种方式写入相同数据。

### 添加设备到拓扑（画布右下角「+」）

点击后弹出「添加设备到拓扑」窗（宽约 700 像素），内嵌设备表格（列：名称 / IP地址 / 类型 / 厂商），带多选列。只列出**尚未加入当前拓扑**的设备（已加入的不再出现）。勾选一台或多台后点「添加」：

- 未勾选点添加提示「请选择至少一个设备」；
- 新节点落在**当前视野中心附近的最近不重叠空位**（批量添加时依次散开，不互相叠压）；
- 设备需先在 [第 5 章 设备管理](./05-devices.md) 中创建才会出现在此列表。

### 拓扑自动发现（画布右下角「放大镜」）

点击后弹出「拓扑自动发现」窗（宽约 600 像素），三步流程：

**第 1 步（选择设备）**：顶部说明文字「选择需要发现拓扑的设备（仅支持 SSH/Telnet 连接的设备）。系统将通过 SSH 采集设备信息，并由 AI 分析设备间的连接关系。」下方是多选下拉框，选项格式「设备名 (IP) - 厂商」，只列出配置了 SSH 或 Telnet 通道的设备。未选设备时「开始发现」按钮禁用。

**第 2 步（采集分析）**：点「开始发现」后显示转圈与进度文案「正在采集设备信息...」。后台流程：AI 先根据设备厂商决定每台设备要执行的信息采集命令（如查看邻居、接口状态的命令）→ 命令逐条经命令白名单校验（不合规的自动跳过）→ 在设备上执行并收集输出 → AI 分析输出推断设备间连接关系。此过程依赖已配置可用的 AI 模型（见 [第 10 章](./10-settings.md)）。

**第 3 步（结果确认）**：完成后显示：

- 绿色结果条「发现 N 个节点、M 条连线」；
- 「发现的节点：」列表（蓝色标签显示设备名，后跟 IP）；
- 「发现的连线：」列表（格式「设备A → 设备B (源接口 - 目标接口)」，接口缺失时省略括号）；
- 「失败的设备：」列表（红色标签设备名 + 具体错误，仅采集失败的设备出现）；
- 全部失败时显示红色「发现失败」错误块。

点「确认并导入 (N 节点, M 连线)」将结果合并进当前拓扑——已存在的节点/连线不会重复导入，导入后提示「导入 N 个节点、M 条连线」；全部已存在时提示「所有节点和连线已存在，无需导入」。点「取消」放弃。

### 画布通用操作

| 操作 | 方式 | 行为 |
| --- | --- | --- |
| 缩放 | 鼠标滚轮 / Controls 按钮 | 以指针为中心缩放 |
| 平移 | 拖动画布空白处 | 移动视野（与框选区分：从空白处起手并拖出范围才进入框选，点按空白即取消全部选中） |
| 取消选中 | 点击画布空白处 | 清空节点与连线选中态，选区工具条消失 |
| 跳转视野 | 点击/拖动小地图 | 快速定位到目标区域 |
| 适配全图 | 左下角 fitView 按钮 | 自动缩放平移使全部节点可见 |
| 删除选中 | 选区工具条「删除」 | 删除选中节点与连线（画布上无 Delete 键直删，删除只经工具条按钮） |

### 多拓扑管理

灵枢支持维护多份拓扑（例如「办公网」「生产网」各一份）。拓扑按最近更新排序显示在下拉框中，默认加载最近更新的一份。各拓扑的节点/连线数据独立保存；同一台设备可以出现在多份拓扑中（节点引用设备，不复制数据）。切换拓扑的路径：侧边栏拓扑选择下拉框；新建/导入后自动切到新拓扑；删除当前拓扑后自动切到列表中下一份（无拓扑时画布清空）。

### 小地图与视图

- 小地图位于画布右上角：缩略显示全部节点位置与当前视野范围，可点击/拖动快速跳转视野。
- 左下角 Controls 工具条：放大、缩小、适配全图（fitView）按钮。
- 打开拓扑时自动适配全图显示。

## 规则与限制

| 规则 | 说明 |
| --- | --- |
| 自动保存 | 停止操作约 1 秒后自动落库；布局预览期间挂起 |
| 页面切换 | 离开拓扑页再回来，画布视图复位（自动适配全图），节点与连线数据不丢 |
| 导入文件格式 | 仅 .json；内容须为灵枢导出的拓扑 JSON 结构 |
| 自动发现范围 | 仅 SSH/Telnet 设备参与；命令执行受白名单约束；依赖 AI 配置 |
| 删除设备与拓扑联动 | 在设备管理页删除设备会同时从拓扑中移除对应节点（见第 5 章） |
| 节点编辑一致性 | 节点属性编辑走设备单一写路径，保存后设备页/拓扑页/AI 上下文同步更新 |
| 重名约束 | 节点改名受全局设备名唯一约束（详见第 5 章「命名全局唯一」） |

## 常见问题

**Q1：拖动节点后其它设备自己动了？**
防重叠设计：松手时被压住的设备自动弹开到最近空位。如果不希望某次排布被改动，可先「整理布局」再微调。

**Q2：双击节点没反应/弹出了表单？**
双击走三分支：未配通道会弹设备表单引导补凭证（顶部有黄色提示）；单通道直接连；多通道弹选择框。连接失败会有带通道名前缀的错误提示。

**Q3：整理布局后不满意？**
布局进入预览态不落库，点横幅上的「撤销布局」一键恢复；或直接拖拽微调后点「保存布局」。

**Q4：自动发现要多久？为什么有的设备失败了？**
耗时取决于设备数量与网络情况（逐台登录执行命令 + AI 分析）。失败列表会给出每台的具体原因（如凭证错误、超时）；只导入成功的部分即可，失败设备修正凭证后可重新发现。

**Q5：自动发现会执行危险命令吗？**
不会。AI 决定的采集命令逐条经命令白名单校验，白名单之外的命令自动跳过不执行。

**Q6：想把拓扑给别人用怎么办？**
侧边栏「导出」得到 JSON 文件，对方在自己库里「导入」即可（对方库中需有同名/同 IP 设备数据才能双击连接）。
