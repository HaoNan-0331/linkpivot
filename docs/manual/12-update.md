# 第 12 章 自动更新

## 功能概述

灵枢内置自动升级：启动时静默检测 GitHub Releases 上的新版本；发现新版且未被你压制时，登录后自动弹出升级弹窗；下载与安装始终需要你显式点击确认，**绝不静默安装**。你也可以随时在系统设置 → 关于页手动检查更新（见 [第 10 章 系统设置](./10-settings.md)）。

## 界面布局

升级功能只有一个弹窗（宽约 520 像素，居中），按所处阶段显示三种形态之一：

- **发现新版本（info）**：版本行 + 更新内容区 + 「不再提醒」区 + 按钮行（左「跳过此版本」文字链接，右「立即升级」主按钮）。
- **正在下载新版本（progress）**：进度条 + 已下载字节数 + 右下「取消」按钮。此形态下弹窗的关闭角标、遮罩点击、ESC 键均被禁用，唯一出口是「取消」按钮。
- **新版本已就绪（ready）**：说明文字 + 重启警告条 + 按钮行（「稍后」与「立即重启安装」主按钮）。

| 元素 | 位置 | 触发条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- | --- |
| 标题「发现新版本」 | 弹窗顶部 | — | — | 按所处阶段自动切换标题 |

## 规则与限制

- **检测时机**：打包版启动后静默检测一次；检测失败无任何提示（不打扰）。开发运行模式无更新检测。
- **自动弹窗时机**：登录后进入主界面时。若上次会话已下载完成但未安装，则优先弹出「新版本已就绪」而不是再次提示检测。
- **压制档位只作用于自动提醒**：手动到设置 → 关于页点「检查更新」永远不受压制影响（包括「永久」档与「跳过此版本」）。
- **档位到期自动恢复**：30 天 / 180 天档到期后自动恢复提醒；「永久」档永久静默；「跳过此版本」只在版本号完全一致时静默。
- **下载失败处理**：下载中途出错自动回退到「发现新版本」可重试态，并提示「下载失败，请稍后重试，或到 Releases 页手动下载。」——不会卡死在下载态。
- **不会静默安装**：应用退出时不会自动安装已下载的更新包，安装必须由你点击「立即重启安装」显式触发。
- **更新日志**：检测、下载完成、失败等关键节点写入后台系统日志表（当前版本不提供界面查询入口）。

## 常见问题

**Q1：我不小心点了「跳过此版本」，这个版本还能装吗？**
能。「跳过」只压制自动提醒；到系统设置 → 关于页点「检查更新」，仍会找到该版本并可升级。

**Q2：选了「永久」不再提醒，后悔了怎么办？**
「永久」档会永久静默启动时的自动提醒，当前版本没有界面开关可以撤销该档位；但手动检查更新不受任何压制——随时在关于页点「检查更新」检测并升级。30 天 / 180 天档到期后会自动恢复提醒。

**Q3：下载到一半断网/失败了？**
弹窗自动回到「发现新版本」态并给出提示，等网络恢复后点「立即升级」重试即可。

**Q4：为什么下载中不能点 X 关闭弹窗？**
防止误触中断下载；设计上用显式的「取消」按钮作为唯一出口，取消后仍可重新下载。

**Q5：重启安装会断开我的 SSH 会话吗？**
会。警告条已提示：重启将断开所有远程会话（SSH / Telnet / MCP），请确认无正在执行的任务后再点「立即重启安装」。
