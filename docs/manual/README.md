# 灵枢（LinkPivot）用户手册

本手册基于灵枢 v0.5.1（master 当前已实现功能）编写。

## 这本手册讲什么

灵枢（LinkPivot）是一个面向运维人员的网络拓扑管理桌面工具：可视化网络拓扑、远程连接并操控设备（SSH / Telnet / Web / RDP）、用 AI 助手辅助分析与执行运维命令、维护设备资料与运维知识库。

本手册覆盖软件中所有可见的界面元素——按钮、输入框、开关、菜单项、弹窗、提示文案、校验规则与边界行为，均可在此查到解释。

## 使用说明

- 新用户：按 1 → 2 → 3 章顺序读完，即可完成安装、登录并认识主界面。
- 日常使用中遇到具体问题：先查第 13 章速查表定位章节，再进对应参考章检索。
- 手册中「首次出现的专业术语」均紧跟一句通俗解释；全部术语汇总在第 14 章。
- 手册为纯文字描述，不含截图；界面元素位置均以文字精确描述（例如「画布左上角工具栏从左到右依次为……」）。
- 手册中的示例数据均为占位值（设备名如「核心交换机-01」，IP 使用 192.0.2.x 等通用示例网段），请替换为你的实际环境信息。
