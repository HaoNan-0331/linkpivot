# 第 10 章 系统设置

## 功能概述

系统设置是管理员主战场：AI 模型与多模态模型配置、命令白名单、执行模式、Agent 任务硬顶、IP 管理的定时采集与保留策略、AI 提示词注册表、MCP 服务与包管理、以及关于页（版本与手动检查更新）。

## 界面布局

页面顶部一行页签，从左到右：「通用设置 | IP 管理 | AI 提示词 | MCP 服务 | 关于」。页面整体限宽约 900 像素居中。切换回「AI 提示词」「MCP 服务」页签时会自动重新加载数据。

## 逐元素详解

### 通用设置页签

从上到下依次为六张卡片/区块：AI 模型配置 → 多模态模型配置 → 命令白名单 → 执行模式 → Agent 任务硬顶 → 退出登录。

#### AI 模型配置卡

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 提供商 | 是 | 下拉三选一：OpenAI / Anthropic / 自定义 |
| API Key | 否* | 密码框，占位「输入 API Key」；已保存的 Key 以脱敏形式回显，未改动时保存不会覆盖真实值 |
| Base URL | 否 | 占位「如 https://api.openai.com/v1（可留空使用默认值）」；兼容 OpenAI 风格中转地址。选「自定义」时必须填写（指向你的 OpenAI 兼容服务地址），官方提供商可留空走默认地址 |
| 模型名称 | 是 | 占位「如 gpt-4o」；留空提示「请输入模型名称」 |

「保存配置」主按钮提交，成功提示「AI 配置已保存」。这是使用 AI 助手的前置条件（未配置时 AI 页显示引导提示）。

#### 多模态模型配置卡

用于知识库图片识别。顶部说明文字：「用于知识库图片识别。未配置时，图片功能将降级（图片仅存储不生成描述）。」字段：Base URL（占位「留空则使用上方 AI 模型的 Base URL」）、API Key（占位「留空则使用上方 AI 模型的 API Key」）、模型名称（占位「如 gpt-4o、claude-3-sonnet（需支持图片输入）」）。可全部留空复用主模型配置。

#### 命令白名单卡

顶部说明：「白名单中的命令模式允许 AI 自动执行，无需人工确认。支持通配符，如 show *」。注意这句成立的条件是执行模式为智能或全自动——默认的「每次确认」模式下，白名单命令仍会逐批弹出审批面板，确认后才执行（见本章常见问题）。另：比对顺序为黑名单优先——内置黑名单首词（shutdown/reboot 等）即使加入白名单也会被拦截，白名单卡不提供黑名单维护（黑名单固定不可改）。

| 元素 | 行为 | 规则与限制 |
| --- | --- | --- |
| 白名单标签墙 | 已有命令模式以可关闭标签展示；点标签上的 × 移除（本地暂存） | 空白名单显示「暂无白名单命令」 |
| 输入框「输入命令模式，如 show *」 | 输入后回车或点「添加」加入 | 重复添加提示「该命令已存在」；空白不可加 |
| 「添加」按钮 | 加入标签墙（未保存） | — |
| 「保存」主按钮 | 整体保存白名单 | 成功提示「白名单已保存」 |

**白名单/黑名单规则语义**：命令安全校验按命令首词判定——先做分隔符注入拦截（防 `show && rm` 类拼接绕过），再比对黑名单首词（命中即拒），最后比对白名单首词（严格相等或通配匹配才放行）。白名单外的命令视为越权，走确认/拦截流程（见 [第 7 章](./07-ai-assistant.md)）。示例：`show *` 放行所有 show 开头的命令；`display` 放行华为系查看命令；具体首词需与设备命令风格一致。

#### 执行模式卡

分段选择器三档，右侧实时显示当前档说明：

| 档位 | 说明文案 | 行为 |
| --- | --- | --- |
| 每次确认（confirm，默认） | 所有命令与工具调用一律弹窗确认，包括已勾免确认的工具（演示/交接时最稳） | 每批命令都出现审批面板 |
| 智能（smart） | 命令与写操作工具弹窗确认，已勾免确认的只读工具直接执行 | 首次切入提示「智能模式：只读且已勾免确认的工具将直接执行」（仅提示一次） |
| 全自动（auto） | 白名单命令与全部工具直接执行，无需确认 | **切换需输管理员密码二次确认**（见下） |

切换到「全自动」时弹出确认窗：「切换到自动执行模式——自动执行模式下，白名单内的命令将由 AI 直接在设备上执行，无需人工确认。MCP 工具调用也将免确认直接在设备上执行。此操作存在风险，请输入管理员密码以确认。」输入管理员密码点「确认切换」生效；密码为空提示「请输入管理员密码」。切换成功提示「已切换为「{模式名}」模式」。注意：任何模式下越权命令仍强制确认（安全底线）。

#### Agent 任务硬顶卡

三个参数行，每行「标签 + 数字输入 + 保存小按钮 + 说明小字」：

| 参数 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| Agent 步数上限 | 1-30 | 12 | AI agent 任务最多执行的步骤数（检索/命令/工具各算一步，含 MCP 工具调用），超限后诚实收尾总结 |
| 连续重复熔断次数 | 1-5 | 2 | 同一设备同一命令连续失败达到该次数后熔断（本轮不再重试，转「需人工处理」） |
| 设备失败冷却（秒） | 10-600 | 60 | 命令失败后该设备同一命令进入冷却，冷却期内不自动重试 |

越界输入自动钳制并提示「已调整为允许范围内的值 {n}」；后台二次校验非法拒绝。卡片底部注明：「调整硬顶参数不改变安全行为：命令/工具执行仍逐条独立执行确认检查与越权检测。」

#### 退出登录按钮

红色按钮，点击立即登出回到登录页（当前会话的远程终端窗口保持，重新登录后可继续）。

### IP 管理页签

**定时采集卡**：一行控件布局——「启用定时采集」开关、「间隔(分钟)」数字框（5~1440，默认 60）、「ARP 保留天数」数字框（0~3650，默认 90，注明「0=永不删除」）、「立即运行」按钮。下方状态行显示「上次运行: {时间}」「下次运行: {时间}」，任务进行中显示蓝色「正在运行中...」。开关切换提示「已启用定时采集」/「已禁用定时采集」。

保留天数采用**失焦/回车提交**（防止输入过程中的瞬态值如 "1"、"18" 触发不可恢复的批量删除）；间隔修改即时生效并重算下次运行时间。

**数据库管理卡**：说明「IP 管理数据存储在拓扑管理数据库中」+「打开数据目录」按钮（提示通过文件管理器访问数据库目录）。数据库自带定期备份与升级前安全备份。

### AI 提示词页签

管理全部内置 AI 提示词的覆盖版本（override）。列表按分组折叠展示全部提示词条目；被修改过的条目带覆盖标记；官方升级后与你的修改冲突的条目带冲突标记（悬停提示「官方默认已更新，需要处理」）。

**进入门槛**：点击任何条目编辑前，需先通过一次性告警门槛——弹窗展示风险告警，要求在输入框中**逐字输入「我已知晓风险」**（照抄引号内原文）；输错提示「输入内容不匹配，请照抄上方引号内的原文」。门槛每次启动应用后重置（登出或重启需重新通过）。

**⚠ 安全关键标记**：部分提示词（影响命令确认与注入防护逻辑的）带红色警示标签「安全关键——修改可能影响命令确认与注入防护，请谨慎」，修改时务必理解后果。

**编辑器**（门槛通过后打开）：

| 元素 | 行为 | 规则与限制 |
| --- | --- | --- |
| 提示词文本框 | 多行编辑当前提示词内容 | 支持变量占位符 |
| 变量文档面板 | 右侧列出全部可用变量：必需变量红标签、可选变量灰标签，附说明 | 点击变量名在光标处插入 `{{变量名}}` |
| 缺失变量即时校验 | 编辑内容缺少必需变量时实时红字提示 | 保存被网关层二次校验拦截 |
| 「保存」 | 保存覆盖版本 | 成功提示「提示词已保存」 |
| 「恢复默认」 | 二次确认后删除覆盖、恢复官方默认 | 确认弹窗防误触 |

**升级冲突三选**：官方升级提示词且你本地有修改时，打开该条目出现三选界面：行内 diff 对比（你的旧版本删除红底、官方新默认新增绿底，Word 修订模式风格）+「仅看变化」开关（折叠未变段落只留上下文）。三个选项：保留我的版本 / 采用官方新默认 / 手动合并后再保存。

### MCP 服务页签

#### MCP 配置区

卡片「MCP 配置」右上「新建配置」主按钮。表格列出全部 MCP 连接器，操作列：「测试 | 工具 | 编辑 | 删除」（删除带确认「删除配置「{名称}」？将同时解除与 N 台设备的绑定。」）。列含绑定设备（悬停看全名单）、最近测试（相对时间如「3 分钟前」）、启用开关（关闭后该连接器不再向 AI 提供工具，配置与设备绑定保留，随时可重新开启）。

**新建/编辑配置弹窗**：

- 配置名称（占位「配置名称（如：设备运维 MCP）」）、类型三选一：本地程序 (stdio) / 网络服务 (http) / MCP 包（仅新建可选，编辑不可改类型）；
- 每次新建 stdio 类型必弹安全告警（本地程序将在本机启动进程，确认来源可信）；
- stdio：命令（占位「如 npx 或完整程序路径」）与参数（逐个添加，输入后按回车确认，占位「如 -y、@modelcontextprotocol/server-everything」）；http：服务地址与令牌（已存令牌脱敏回显，留空不修改，可显式清除）；
- 设备级环境变量区（见下）；
- 表单内「测试连接」：即时用当前输入（含未保存明文）发起测试；行操作「测试」用已保存配置测试并落库结果。

**测试过程面板**：三阶段进度「正在启动程序… → 正在建立连接… → 正在获取工具清单…」（附已耗时秒数与「取消」按钮）；成功显示「连接成功 · 协议版本 {v} · 共 N 个工具」+ 工具表（名称/描述/只读标签），点工具行开抽屉看详情；失败显示「连接失败」+ 错误原因与错误码及建议「可检查命令/地址与凭证后重试」。

**工具管理抽屉**（行操作「工具」）：该连接器全部工具的策略表——名称、描述、只读标注（「只读」绿标签，名字经核验的显示「已验证只读」）、启用开关、免确认勾选。免确认可勾性由后台判定：只有被服务声明为只读（readOnlyHint）的工具才可勾；否则勾选框禁用并提示「该工具未被 MCP server 声明为只读（readOnlyHint），只能逐次确认」。勾选免确认提示「已设为免确认：{工具名} 将在「智能」档下直接执行（「每次确认」档仍会弹窗）」。

#### 设备环境凭证区

配置绑定设备的 MCP 环境变量（凭证类值经此注入，不进命令行参数）：

- 「绑定设备」按钮：弹窗选择设备（占位「选择要绑定的设备」），确认后为该设备添加变量组；
- 每台已绑定设备一张卡：变量行（变量名 + 值 + 删除），「＋添加变量」按钮；值为空时占位提示「留空将使用包默认 {默认值}」；包声明的必填项缺失时保存被拦（提示哪台设备缺哪个必填项）；
- 包的变量说明（EnvKeyMetaList）：列出包声明的变量元数据，必填项带红「必填」标签。

#### MCP 包区（平级卡片）

右上「导入」主按钮为唯一导入入口。导入 .mcpb 包文件时执行五向量安全校验（逐项 ✓/✗ 与失败原因人话展示），含 SHA-256 指纹登记（防内容被替换——重导时指纹并排对比，内容变化需确认覆盖）。包列表操作：「重测」（重新校验测试）「指纹」（查看 SHA-256 指纹）「导出」（导出 .mcpb 包格式说明文件，成功提示「已导出到 {路径}」，用于按规范自制包）「删除」。覆盖确认弹窗并列展示新旧指纹与 env 键变化三清单，确认后替换。

### 关于页签

「关于本应用」卡片：当前版本号显示；主按钮「检查更新」（手动全解禁——不受「不再提醒/跳过版本」压制）；Releases 发布页直链；状态行七态展示（未检查更新 / 正在检查更新… / 已是最新版本 vX / 发现新版本 vX / 正在下载新版本… N% / 已下载待安装 / 上次检查更新失败）；已是最新时气泡提示「已是最新版本 vX」不弹窗；已下载待安装时出现第二个主按钮「立即重启安装」（弹窗未开也能装）。

检查失败按六类错误分诊给出人话文案（网络/代理/限流/无发布元数据/服务器/未知），三类内嵌手动下载链接；统一兜底文案「检查更新失败，请稍后重试，或到 Releases 页手动下载。」升级弹窗全流程见 [第 12 章 自动更新](./12-update.md)。

## 典型配置流程：从零启用 AI 能力

1. 设置 → 通用设置 → 「AI 模型配置」卡：选提供商、填 API Key、按需改 Base URL（用中转服务时填中转地址）、填模型名称，点「保存配置」。预期提示「AI 配置已保存」。
2. （可选）「多模态模型配置」卡：填支持图片输入的模型名（如 gpt-4o），其余留空复用主配置。预期保存后知识库图片识别生效。
3. 「命令白名单」卡：按你设备族的命令风格添加只读查看类命令模式（如 `show *`、`display`、`ping`），点「保存」。预期提示「白名单已保存」。
4. 「执行模式」卡：日常建议保持「每次确认」；熟悉后可切「智能」；「全自动」需输管理员密码。
5. 到 [第 7 章](./07-ai-assistant.md) 验证：AI 页不再显示配置引导，可正常对话。

## 典型配置流程：接入一个 MCP 连接器

1. 设置 → MCP 服务 → 「新建配置」。预期弹出配置表单（stdio 类型附安全告警——确认工具来源可信）。
2. 选类型（本地程序 stdio / 网络服务 http），填名称与命令/地址；如需凭证在设备环境变量区「绑定设备」并添加变量（必填项缺失会在保存时被拦并指明缺哪个）。
3. 点表单内「测试连接」。预期看到三阶段进度，成功显示工具清单（名称/描述/只读标注）。
4. 保存配置（提示「配置已创建」），列表出现新行。
5. 点行操作「工具」打开工具管理抽屉：按需调整每个工具的启用与免确认（只读工具才可勾免确认）。预期勾选提示生效档位说明。
6. 到 AI 助手的设备选择器确认目标设备出现「可调MCP」蓝色标签。

## 规则与限制

| 规则 | 说明 |
| --- | --- |
| Key 脱敏保存 | API Key 以掩码回显；未改动的掩码串不会落库覆盖真实 Key（双层防护） |
| 全自动模式门槛 | 切换 auto 必须输入管理员密码；越权命令在任何模式下仍强制确认 |
| 提示词门槛 | 编辑提示词需逐字输入「我已知晓风险」过门槛；门槛仅会话内有效 |
| 提示词冲突 | 官方升级与本地修改冲突时必须三选处理（保留我的/采用官方/手动合并） |
| 占位符校验 | 提示词缺必需变量被实时提示 + 保存时网关层拦截 |
| 白名单保存 | 标签墙编辑后必须点「保存」才生效；重复项不可加 |
| 硬顶双防线 | 界面钳制 + 后台硬校验；调参不影响确认与越权检测 |
| 保留天数提交 | 失焦/回车才提交（防瞬态值触发批量删除）；0=永不删除 |
| MCP 凭证 | 环境变量加密存储；stdio 每次新建弹安全告警；http 令牌脱敏留空不改 |
| 包指纹 | .mcpb 导入五向量校验 + SHA-256 指纹；内容变化覆盖需确认 |
| 免确认资格 | 仅服务声明只读的工具可设免确认；「每次确认」档下仍弹窗 |

## 常见问题

**Q1：API Key 填了之后显示 ****，是没存上吗？**
存上了。已保存的 Key 以脱敏形式回显；只要你不改这个字段，保存其它配置不会覆盖真实 Key。

**Q2：白名单加了 `show *` 为什么 AI 还是弹确认？**
两种可能：当前执行模式是「每次确认」（此档一律确认，含白名单命令）；或命令首词不在白名单命中范围（通配只作用于首词模式）。切到「智能」或「全自动」后白名单命令才免确认。

**Q3：切「全自动」要求的管理员密码是什么？**
就是登录灵枢用的管理员账号密码（安全二次确认，防止误开全自动）。

**Q4：提示词门槛每次都要输「我已知晓风险」？**
每次启动应用后的首次编辑需要一次；同一会话内后续编辑不再要求。登出或重启后重置。

**Q5：官方升级后我的提示词改去哪了？**
你的版本仍在，对应条目出现冲突标记；打开后三选处理，diff 视图可「仅看变化」快速定位差异。

**Q6：MCP 工具勾不了「免确认」？**
该工具未被 MCP 服务声明为只读。只有只读工具可设免确认；写操作类工具任何情况下都要确认。

**Q7：想手动看看有没有新版本？**
设置 → 关于 → 「检查更新」。手动检查不受任何压制档位影响，最坏也会给出失败原因与手动下载链接。

**Q8：定时采集间隔改了立即生效吗？**
立即生效并重算「下次运行」时间；正在运行的任务不受影响。

**Q9：退出登录会断开已开的终端窗口吗？**
不会。退出登录回到登录页，已打开的 SSH/Telnet 终端窗口与远程会话保持；退出整个应用才会全部断开。

**Q10：「IP 管理」页签的数据库管理与设备数据是同一个库吗？**
是。ARP 采集等 IP 管理数据与设备/拓扑数据同库存储，共用同一套备份与迁移机制。

**Q11：提示词改坏了怎么恢复？**
编辑器里的「恢复默认」可一键回到官方默认（有二次确认）；冲突条目也可在三选里直接「采用官方新默认」。

**Q12：MCP 配置删了，绑定的设备环境变量怎么办？**
删除配置时提示会同时解除与 N 台设备的绑定；设备级变量随绑定一并清理，不会残留孤儿数据。
