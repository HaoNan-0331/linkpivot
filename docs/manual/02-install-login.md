# 第 2 章 安装与登录

本章带你从零开始：安装灵枢 → 首次启动初始化管理员 → 日常登录。每一步都写明「预期看到什么」。

## 安装

**第 1 步：获取安装包。**
从官方发布页（GitHub Releases）下载 Windows 安装包，文件名形如 `灵枢-0.5.1-Setup.exe`（0.x 为版本号，随发布更新）。

**第 2 步：运行安装包。**
双击 Setup.exe，按 NSIS 安装向导（Windows 上常见的标准安装程序界面）逐步完成安装。安装过程无需额外依赖，不需要预先安装 Node.js 或数据库。

**第 3 步：启动灵枢。**
从开始菜单或桌面快捷方式启动。预期看到：一个居中的加载转圈，随后进入以下两者之一：

- 全新安装（本地无账号数据）→ 进入「初始化管理员账号」界面（见下节）。
- 已初始化过 → 进入「登录」界面。

## 首次启动：初始化管理员

首次启动时数据库中没有账号，灵枢会显示「初始化管理员账号」卡片（居中，宽约 400 像素），包含三个输入框和一个按钮，从上到下为：

| 元素 | 位置 | 说明 |
| --- | --- | --- |
| 标题「初始化管理员账号」 | 卡片顶部居中 | — |
| 用户名输入框 | 第一行 | 占位提示「管理员用户名」，必填 |
| 密码输入框 | 第二行 | 占位提示「密码（不低于 10 位，需同时包含字母和数字）」，必填，内容以圆点遮蔽 |
| 确认密码输入框 | 第三行 | 占位提示「确认密码」，必填，内容以圆点遮蔽 |
| 「创建管理员」按钮 | 底部通栏 | 主按钮，提交后进入 loading 状态 |

**操作步骤：**

1. 输入管理员用户名。留空提交会在输入框下方提示「请输入用户名」。
2. 输入密码。密码策略（两条规则，均由表单与后台双重校验）：
   - 长度不低于 10 位，不满足提示「密码不低于 10 位」；
   - 需同时包含字母和数字，不满足提示「密码需同时包含字母和数字」。
3. 再输入一遍密码。两次不一致时提交会弹出错误提示「两次密码不一致」；留空提示「请确认密码」。
4. 点击「创建管理员」。

**预期结果：** 成功时弹出「管理员创建成功」，页面自动刷新进入登录界面。

**边界行为：**

- 管理员只能在首次启动创建。若数据库中已存在账号，再次触发初始化会返回「管理员已初始化，仅首次启动可创建」——正常使用中不会遇到此界面第二次。
- 用户名重复时提示「用户名已存在」。
- 管理员密码同样受上述密码策略约束（后台二次校验，绕过表单直调也会被拒绝）。

## 日常登录

每次启动灵枢都需要登录（登录态不跨启动保留，关闭应用后下次启动需重新登录）。登录卡片居中显示，标题为「灵枢」。

| 元素 | 位置 | 说明 |
| --- | --- | --- |
| 标题「灵枢」 | 卡片顶部居中 | 产品名 |
| 用户名输入框 | 第一行 | 占位提示「用户名」，必填 |
| 密码输入框 | 第二行 | 占位提示「密码」，必填，内容以圆点遮蔽 |
| 验证码输入框 | 第三行 | 占位提示「验证码」，必填 |
| 验证码图片 + 「换一张」按钮 | 第四行 | 左侧为 4 位字符的验证码图片，右侧为「换一张」文字按钮 |
| 「登录」按钮 | 底部通栏 | 主按钮，提交后进入 loading 状态 |

**操作步骤：**

1. 输入用户名、密码。留空时对应输入框会标红要求必填。
2. 查看验证码图片，输入图中的 4 个字符（不区分大小写）。验证码字符集刻意排除了易混淆的 I、O、0、1。
3. 看不清可点击验证码图片本身或「换一张」按钮刷新；刷新后验证码输入框会自动清空。
4. 点击「登录」。

**预期结果：** 成功后进入主界面（见 [第 3 章 界面总览](./03-ui-tour.md)）。

**失败与边界行为：**

| 场景 | 提示文案 | 后续行为 |
| --- | --- | --- |
| 验证码输错/过期 | 「验证码错误」 | 自动刷新验证码并清空验证码输入框 |
| 用户名或密码错误 | 「用户名或密码错误」 | 自动刷新验证码（不提示具体是哪项错，防账号枚举） |
| 连续失败 5 次 | 「登录失败次数过多，请 5 分钟后再试」 | 该用户名被锁定 5 分钟，锁定期内即使密码正确也拒绝登录；锁定为内存态，重启应用即清零 |
| 验证码有效期 | 无提示（按过期处理） | 每个验证码 5 分钟内有效且只能使用一次 |

> 提示：锁定计数按用户名累计，登录成功一次即清零。

## 登录后进入主界面

登录成功后首先进入的是「拓扑管理」页（默认路由）。如果你是全新安装，此时拓扑是空的，下一步通常是：

1. 到 [第 5 章 设备管理](./05-devices.md) 添加你的第一台设备（含登录凭证）；
2. 到 [第 4 章 拓扑管理](./04-topology.md) 用自动发现生成拓扑，或手动摆放节点；
3. 到 [第 10 章 系统设置](./10-settings.md) 配置 AI 模型（不配置 AI 也能用拓扑/设备/终端功能）。

## 数据存放位置与迁移注意

- 灵枢的全部数据存放在本机用户数据目录（Windows 下为 `%APPDATA%` 对应的灵枢目录）中的 SQLite 数据库及相关文件里，不上传云端。
- 设备凭证等敏感字段是加密存储的，加密根密钥绑定本机与本 Windows 账户（原理见 [第 1 章](./01-overview.md)「安全机制通俗说明」）。**只拷贝数据库文件到别的机器是无法解密凭证的**；整机迁移时需连同整个用户数据目录一起迁移，且目标机器使用相同的 Windows 用户账户环境。
- 数据库自带定期备份（双桶轮换，即始终保留新旧两份备份交替覆盖）与升级前安全备份。

## 常见问题

**Q1：忘了管理员密码怎么办？**
灵枢不提供找回密码功能（单机软件，无邮箱等找回通道）。处理方式是从用户数据目录的 backups 备份恢复早期数据库文件，或接受数据重置（删除用户数据目录后重新初始化）。日常建议把密码记在安全的密码管理工具中。

**Q2：为什么每次启动都要重新登录？**
登录态保存在内存中，应用关闭即失效，这是桌面安全工具的常见设计：防止他人直接打开你留在电脑上的灵枢就接触到设备凭证与远程通道。

**Q3：密码策略具体是什么？**
不低于 10 位，且需同时包含字母和数字。这是唯一强制的组合规则，特殊字符不强制但允许使用。

**Q4：验证码总是看不清？**
点击验证码图片或「换一张」即可刷新。字符集已排除 I、O、0、1 这四个最易混淆的字符。

**Q5：登录时提示锁定 5 分钟，能立即解锁吗？**
不能从界面解锁。等待 5 分钟，或重启灵枢（锁定状态存内存，重启即清零）。

## 本章术语

| 术语 | 解释 |
| --- | --- |
| NSIS | Windows 上常见的标准安装程序框架，灵枢安装包基于它 |
| 验证码 | 登录时图片中展示的 4 位字符，用于防止自动化暴力尝试密码 |
| 账号锁定 | 连续 5 次登录失败后该用户名 5 分钟内禁止再试的保护机制 |
| loading 状态 | 按钮提交后显示转圈并暂时不可再点的状态 |
| 必填 | 输入框为空时提交会被拦截并标红提示的字段 |
| 双桶轮换备份 | 始终保留新旧两份备份文件交替覆盖的备份策略 |
