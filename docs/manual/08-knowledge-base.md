# 第 8 章 知识库

## 功能概述

知识库管理两类知识资产：「文档」（上传的运维资料，自动解析分块、建全文索引，供检索与 AI 引用）与「经验」（结构化运维经验条目，可手动录入或由 AI 对话起草沉淀）。进入页面默认显示「文档」页签，经验页签首次切换时才加载。

## 界面布局

页面顶部一行页签：「文档 | 经验」。

- 文档页签：两张卡片纵向排列——上卡「知识库」（上传/筛选/文档表格），下卡「检索测试」（搜索框 + 命中片段列表）。
- 经验页签：筛选工具栏（八个控件）+ 经验表格（每页 20 条）。

## 逐元素详解

### 文档页签

#### 上传与筛选（「知识库」卡片）

| 元素 | 位置 | 触发条件 | 行为 | 规则与限制 |
| --- | --- | --- | --- | --- |
| 「上传文档」主按钮 | 卡片工具行左侧 | 点击 | 打开文件选择器（仅接受 .txt / .pdf / .doc / .docx），选定后弹出「上传文档」确认窗：选择分类（固定四类：手册/API文档/配置模板/笔记，当前版本不可自定义）与关联设备（可选，「全局文档」为默认） | 不支持的扩展名提示「仅支持 TXT、PDF、Word 文件」；成功提示「{文件名} 上传成功」 |
| 「筛选设备」下拉 | 上传按钮右侧 | 选择 | 按关联设备过滤文档列表 | 可清空恢复全部 |
| 「筛选分类」下拉 | 最右 | 选择 | 按分类过滤文档列表 | 可清空 |

上传后文档进入解析流水线，状态经历「待处理 → 处理中 → 就绪」（或「失败」）；列表每 2 秒自动刷新直到处理完成。PDF/DOCX 会抽取正文分块并建全文索引；文档中的图片会做多模态识别（调用视觉模型把图片内容转成文字描述），识别结果同样可被检索命中。

#### 文档表格

列：文件名（带类型图标：PDF 红色 / Word 蓝色 / 文本灰色，点击文件名打开文档详情）/ 分类 / 关联设备（「全局」灰标签或设备名）/ 大小 / 分块数 / 状态 / 上传时间 / 操作。

状态标签：待处理（灰）/ 处理中（蓝，动态）/ 就绪（绿）/ 失败（红，下方红色小字显示具体错误信息）。

操作列：

| 按钮 | 显示条件 | 行为 |
| --- | --- | --- |
| 「重试」 | 状态为失败 | 重新提交解析，提示「已重新提交处理」 |
| 「删除」红色按钮 | 恒显 | 气泡确认「确认删除——将删除文档"{文件名}"及其所有分块数据」；失败提示「操作失败，数据已回滚无变化：…」 |

#### 检索测试卡片

| 元素 | 行为 | 规则与限制 |
| --- | --- | --- |
| 搜索框「输入关键词检索文档片段」+「检索」主按钮 | 执行全文检索（回车等效） | 空关键词不触发 |
| 降级提示条（黄色） | AI 筛选不可用时显示「AI 筛选不可用，已降级为关键词匹配」 | 检索链路：全文索引粗筛 → AI 从候选中挑选最相关片段；AI 不可用时退回纯关键词匹配 |
| 截断提示 | 索引候选超上限时显示「已从 N 条截取前 M 条」 | — |
| 结果列表 | 每条一张小卡：序号蓝标签 + 片段标题 + 来源文档名，正文预览（最高约 300 像素滚动） | 正文中的图片位置以 `[图片N]` 标记呈现，图片加载后直接显示缩略图，点击放大预览（全屏遮罩，点任意处关闭） |

#### 文档详情弹窗（点击文件名）

宽约 900 像素，顶部显示文件名、状态标签、分块数；选中 ≥2 个分块时出现「合并选中(N)」主按钮。每个分块一张卡片：勾选框 + 序号标签 + 标题（可编辑态变输入框）+ 字数，右侧操作按钮组，正文预览（图片内嵌显示）。

| 操作 | 行为 | 规则与限制 |
| --- | --- | --- |
| 「编辑」 | 标题与内容进入行内编辑（内容变多行文本框） | 「保存」提示「保存成功」；「取消」放弃 |
| 「拆分」 | 弹「拆分章节」窗：拆分位置（字符偏移数字）、上半部分标题、下半部分标题 | 默认位置为内容中点；成功提示「拆分成功」 |
| 「删除」红色按钮 | 气泡确认「确认删除此章节？」 | 提示「章节已删除」 |
| 「合并选中(N)」 | 弹窗输入合并后标题（默认为各标题以「 + 」连接） | 至少选 2 个章节（少于 2 个点击时提示「请至少选择2个章节」）；成功提示「合并成功」 |

### 经验页签

#### 筛选工具栏（从左到右八个控件）

| 控件 | 说明 |
| --- | --- |
| 「新增经验」主按钮 | 打开新增经验表单 |
| 搜索框「搜索经验标题或正文」 | 240 像素宽，输入约 0.3 秒自动查询，回车立即查 |
| 分类下拉 | 故障排查 / 最佳实践 / 产品 / 环境 |
| 严重度下拉 | 致命 / 高 / 中 / 低 / 提示 |
| 状态下拉 | 有效 / 已失效；选「已失效」自动打开显示失效开关，选「有效」自动关闭 |
| 设备多选下拉「筛选设备」 | 按关联设备过滤 |
| 标签多选下拉「筛选标签」 | 候选来自当前页条目的标签 |
| 「显示已失效」开关 | 独立控制是否包含已失效条目 |

#### 经验表格（九列）

标题（链接，点击打开详情弹窗）/ 分类（蓝标签）/ 严重程度（仅故障排查类显示彩色标签，其它类显示「—」）/ 标签（最多显示 3 个，超出显示「+N」）/ 关联设备（「N 台」或「全局」灰标签）/ 状态（「有效」绿或「已失效」灰）/ 有效期（起始 ~ 至今，或起始 ~ 失效时间红色）/ 最后验证（时间或「未验证」灰色）/ 操作。

操作列按状态显示：「编辑」「标失效」「删除」或「编辑」「恢复有效」「删除」：

- 「标失效」：气泡确认「标记为失效？——失效后将从默认视图剔除，但仍可查/可恢复，不会物理删除。」，提示「已标记为失效」；
- 「恢复有效」：提示「已恢复为有效」；
- 「删除」：气泡确认「确认删除——将彻底删除经验『{标题}』，操作不可恢复。」。

#### 经验详情弹窗

展示完整内容与元数据。来源会话行：AI 起草的经验显示来源会话标识与「查看原始会话」按钮（打开当时的完整对话记录弹窗，供溯源核对）；手动录入的显示「手动录入」。底部按钮：编辑 / 标失效（或恢复有效）/ 删除（红色）。

#### 新增/编辑经验表单（弹窗宽约 640 像素）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是（非故障排查类时） | 文本。故障排查类以「故障现象/解决办法」等结构化字段承载核心信息，标题可选；其余三类以标题+内容为主干，必填 |
| 分类 | 是 | 固定四选一：故障排查 / 最佳实践 / 产品 / 环境（不可自定义） |
| 内容 | 是 | 多行文本 |
| 标签 | 否 | 多选输入，自定义标签 |
| 严重程度 | 故障排查类必填 | 致命 / 高 / 中 / 低 / 提示 |
| 故障现象 | 故障排查类必填 | 多行文本 |
| 根本原因 | 否 | 多行文本 |
| 解决办法 | 故障排查类必填 | 多行文本 |
| 预防措施 | 否 | 多行文本 |
| 关联设备 | 否 | 多选设备（全部类型设备可选），编辑态占位「不改关联则留空」 |

质量门实时校验：故障排查类缺严重程度/故障现象/解决办法时底部列出「缺 严重程度」「缺 故障现象」「缺 解决办法」，缺项时禁止提交。手动新增的经验直接为「有效」状态（人工录入非 AI 产出，无需再走确认流）；AI 起草的经验须经确认流（见 [第 7 章](./07-ai-assistant.md)）。

## 典型操作流程：让 AI 用上你的资料

1. 知识库 → 文档页签 → 点「上传文档」，选择一份 PDF 手册。预期弹出确认窗，选好分类与关联设备（可不关联），点确定后提示「{文件名} 上传成功」。
2. 观察文档状态：待处理 → 处理中 → 就绪（列表自动刷新，无需手动操作）。预期就绪后「分块数」列显示解析出的章节数。
3. 在下方「检索测试」输入手册中的关键词（如某报错码），点「检索」。预期出现命中片段卡片，正文含 [图片N] 的位置显示图片缩略图。
4. 打开 [第 7 章 AI 助手](./07-ai-assistant.md)，向 AI 提问相关问题。预期 AI 的回答引用了手册内容，消息底部出现「知识库」来源徽章。
5. 有价值的处理过程可在 AI 对话中沉淀为经验（AI 起草确认流见第 7 章），或到经验页签点「新增经验」手动录入。

## 经验生命周期

```
手动录入 ──────────────► 有效（published）
                           │        ▲
                        标失效      恢复有效
                           │        │
                           ▼        │
                        已失效（invalid，软归档：列表可查、可恢复）
                           │
                        删除（物理删除，不可恢复）

AI 对话 ──经验起草──► 草稿（draft，待确认）──人工确认──► 有效
                        │
                     丢弃（草稿直接删除）
```

- 有效经验参与 AI 检索复用；已失效经验默认隐藏（打开「显示已失效」开关或状态筛选可查），AI 不再引用。
- AI 复用一条有效经验作答前会再校验其有效期与命令安全性，过期或不安全的经验自动跳过。
- 每次被 AI 命中复用，经验的复用次数加一、最后验证时间刷新——这两个字段可作为经验质量的参考。

## 规则与限制

| 规则 | 说明 |
| --- | --- |
| 支持格式 | 文档：TXT / PDF / DOC / DOCX；其他类型上传被拦截 |
| 解析状态机 | 待处理 → 处理中 → 就绪/失败；处理中文档列表每 2 秒轮询刷新 |
| 重新处理 | 失败文档可「重试」重新解析；删除与重试均事务化 |
| 分块编辑 | 分块（章节）标题与内容可编辑、可拆分（按字符偏移）、可两两合并 |
| 检索两段式 | 全文索引（FTS5）粗筛 → AI 精选；AI 不可用自动降级关键词匹配（黄色提示） |
| 图片识别 | 文档图片做多模态识别生成文字描述；正文以 [图片N] 占位，图片按需加载缩略图 |
| 经验软失效 | 「标失效」是软删除（可恢复），「删除」是物理删除不可恢复 |
| 分页 | 经验列表服务端分页固定 20 条/页；筛选变化自动回第 1 页 |
| AI 检索复用 | AI 回答时命中的经验会自动累计复用次数并刷新最后验证时间（见第 7 章） |
| 加密 | 经验条目的结构化属性区加密存储 |

## 常见问题

**Q1：上传 PDF 后一直「处理中」？**
大文件解析需要时间（含图片识别时更久），列表会自动刷新；若长时间停在处理中或变「失败」，失败原因会显示在状态列下方。

**Q2：检索「AI 筛选不可用，已降级为关键词匹配」？**
AI 模型未配置或调用失败时，检索退回纯关键词模式，结果仍可用；到系统设置检查 AI 配置可恢复精选模式。

**Q3：怎么把一份大手册里无关的章节合并/拆整齐？**
打开文档详情，勾选多个分块点「合并选中」；或对过长分块点「拆分」按字符位置一分为二，再分别改标题。

**Q4：AI 起草的经验和手动录入的有什么区别？**
内容结构相同。区别：AI 起草带来源会话（可回看原始对话）且必须经人工确认后才生效；手动录入直接生效。

**Q5：经验「失效」和「删除」选哪个？**
失效是可逆的归档（条件过时了但历史可查），删除是不可恢复的物理清除。不确定时先标失效。

**Q6：关联设备有什么用？**
AI 在针对某设备回答问题时会优先检索与该设备关联的经验；关联是元数据引用，不代表设备连接能力。

**Q7：文档支持多大的文件？**
以本地解析为主，常见手册级文件均可；过大的 PDF 解析时间较长（处理中状态会持续），图片多的文档还需额外的识别时间。

**Q8：检索命中的顺序是按什么排的？**
先全文索引粗筛（关键词相关度），再由 AI 从候选中挑选最相关片段排序；AI 不可用时按关键词匹配结果排序（顶部有降级提示）。

**Q9：手动录入的经验也要 AI 确认吗？**
不用。人工录入直接生效（有效状态）；只有 AI 起草的条目才走「确认后发布」的人工闸口。

**Q10：经验页签的「最后验证」是什么时候更新的？**
两种情况：AI 检索复用该经验作答时自动刷新；手动编辑保存时刷新。长时间未验证的经验可考虑复核或标失效。

## 本章术语

| 术语 | 解释 |
| --- | --- |
| 分块/章节 | 文档解析后切成的可检索单元，可编辑/拆分/合并 |
| 全文索引 | FTS5 引擎按关键词定位分块的粗筛机制 |
| 降级检索 | AI 精选不可用时退回关键词匹配的兜底模式 |
| 多模态识别 | 用视觉模型把文档图片内容转成文字描述供检索 |
| [图片N] 占位 | 正文中图片位置的标记，加载后显示缩略图 |
| 经验条目 | 结构化运维经验（分类/严重度/现象/解决办法等） |
| 软失效 | 标记失效但保留数据、可恢复的归档操作 |
| 来源会话 | AI 起草经验时所依据的对话记录，可回看溯源 |
| 质量门 | 提交前按分类校验必填项的实时检查 |
| 复用次数 | 经验被 AI 检索命中并用于回答的累计计数 |
| 草稿 | AI 起草后等待人工确认的经验中间态 |
| 硬删除 | 物理删除数据行、不可恢复的删除方式 |
| 分类 | 经验的四类：故障排查 / 最佳实践 / 产品 / 环境 |
| 严重程度 | 故障排查类经验的等级：致命 / 高 / 中 / 低 / 提示 |
| 全局文档 | 未关联具体设备、对所有设备通用的文档 |
