# 第 13 章 速查表

## 功能概述

「我想做 X → 去哪操作」对照表。按日常工作场景组织，每条给出操作路径与详述章节链接。按设备、拓扑、远程连接、IP 管理、AI、知识库与日志、全局与更新七个分组组织。

## 我想做 X → 去哪操作

### 设备相关

| 我想做… | 去哪操作 | 详见 |
| --- | --- | --- |
| 添加一台新设备（含登录凭证） | 设备管理 → 添加设备 → 填基本信息 + 通道页签凭证 → 确定 | [第 5 章](./05-devices.md) |
| 修改设备密码（怕被清掉） | 设备管理 → 编辑 → 对应通道页签，密码栏留空=不改，输入新值=覆盖 | [第 5 章](./05-devices.md) |
| 给一台设备加第二类登录通道 | 设备管理 → 编辑 → 打开另一通道页签开关并填凭证 → 默认通道按需改选 | [第 5 章](./05-devices.md) |
| 测试设备连不通的原因 | 设备管理 → 操作列「测试连接」（多通道设备逐通道并行报告） | [第 5 章](./05-devices.md) |
| 复制一台相似设备 | 设备管理 → 操作列「复制」→ 改名改 IP（凭证必须重输） | [第 5 章](./05-devices.md) |
| 处理重名设备提示 | 设备管理 → 提示条「查看清单」→ 重名清单弹窗内联改名至清零 | [第 5 章](./05-devices.md) |
| 删除设备 | 设备管理 → 操作列删除（确认后连同拓扑节点级联移除） | [第 5 章](./05-devices.md) |

## 使用提示

- 找不到想做的事：用各章「逐元素详解」表格按界面区域检索元素。
- 看不懂术语：查 [第 14 章 术语表](./14-glossary.md)。
- 界面出现意外提示：查对应章「规则与限制」与「常见问题」小节。
